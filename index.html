📌 如何取得 Google Client ID？

  1. 前往 Google Cloud Console
  2. 建立新專案或選擇現有專案
  3. 啟用「Google Calendar API」
  4. 建立「OAuth 2.0 用戶端 ID」（網頁應用程式）
  5. 「已授權的 JavaScript 來源」填入本 App 網址
  6. 複製 Client ID 貼入下方
Client ID 僅儲存於本機瀏覽器，不會上傳至任何伺服器
